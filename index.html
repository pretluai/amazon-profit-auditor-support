隐私说明

本扩展用于在用户浏览器中汇总结算文件并进行文件内金额检查。

报表文件由用户主动选择，文件内容只在当前扩展页面内解析和显示。扩展不将文件内容、文件名、订单信息或计算结果发送到开发者或第三方服务器。扩展不自动访问 Seller Central，不读取其他网页、浏览历史、密码或账户凭证。

扩展不包含广告、遥测、分析追踪服务或远程执行代码。当前版本不发起网络请求。

语言偏好通过浏览器本地存储保存。报表内容不由扩展持久保存，刷新或关闭扩展页面会清空当前导入状态。用户主动导出的 CSV 文件保存在本机下载位置，可自行删除。卸载扩展会清除扩展的本地偏好。

扩展不出售或共享用户数据，也不用于广告投放、信用评估或借贷决策。

此说明仅适用于扩展自身。Chrome 浏览器、操作系统和其他已安装扩展的行为，由其各自的隐私说明和设置决定。

Privacy notice

The extension summarizes settlement files and checks amounts within a file in the user's browser.

Users explicitly select report files. File content is parsed and displayed only in the current extension page. The extension does not send report content, filenames, order information or results to the developer or third-party servers. It does not automatically access Seller Central or read other websites, browsing history, passwords or account credentials.

The extension includes no advertising, telemetry, analytics trackers or remotely executed code. The current version makes no network requests.

Language preference is saved in browser local storage. Reports are not persistently stored by the extension. Refreshing or closing the extension page clears the imported state. CSV files exported by the user remain in the local download location and can be deleted by the user. Uninstalling the extension removes its local preferences.

The extension does not sell or share user data or use it for advertising, creditworthiness assessments or lending decisions.

This notice describes the extension itself. Chrome, the operating system and other installed extensions have their own settings and privacy notices.

This independent tool is not affiliated with or endorsed by Amazon.
本工具与 Amazon 无隶属或认可关系。

Website hosting may process standard connection information such as IP address and request logs under the hosting provider’s policies. The website has no report upload form or analytics scripts. These hosting operations are separate from the extension’s local report processing.

网页托管服务可能按其政策处理 IP 地址和请求日志等连接信息。此网页没有报表上传入口或分析追踪脚本；网页托管与扩展本地报表处理相互独立。
